================================================================================
┌─────────────────────────────────────────────────────────────────────────────┐
│ HTTP Method: POST                                                           │
│ URL: /api/v1/auth/register                                                 │
│ الوصف: تسجيل مستخدم جديد في النظام                                         │
└─────────────────────────────────────────────────────────────────────────────┘

► الطلب (Request Body):
{

    "email": "ahmed@example.com",      // البريد الإلكتروني - مطلوب
    "phoneNumber": "0555123456",       // رقم الجوال - مطلوب - 10 أرقام
    "password": "P@ssw0rd123",         // كلمة المرور - مطلوب - 8 أحرف على الأقل

        "email": "ahmed@example.com",
        "role": "Applicant"
    },
    "errors": null,
    "statusCode": 201
}

► الاستجابة (Validation Error - 400 Bad Request):

    "success": false,
    "message": "فشل التحقق من البيانات",

    "errors": [

    "statusCode": 400

► المصادقة:

  - تتضمن الصلاحيات: Applicant, Receptionist, Doctor, Examiner, Manager, Admin

► معالجة الأخطاء:
  - 400: خطأ في التحقق من البيانات
  - 401: غير مصادق أو رمز منتهي الصلاحية
  - 403: غير مصرح بالوصول
  - 404: المورد غير موجود
  - 409: تعارض (مثل موعد محجوز مسبقاً)
  - 500: خطأ داخلي في الخادم

  - تسجيل الدخول: 10 طلب في الدقيقة
  - تسجيل حساب جديد: 5 طلبات في الدقيقة
  - OTP: 3 محاولات كحد أقصى
