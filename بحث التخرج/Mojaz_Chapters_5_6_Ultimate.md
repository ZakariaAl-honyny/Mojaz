# الفصول الختامية (الفصل الخامس والسادس): التنفيذ، الاختبار، والخاتمة

هذا المستند يكمل رحلة البحث الأكاديمي لمنصة "مجاز"، حيث يركز على الجوانب الميدانية للتطبيق ونتائج الاختبارات والتوصيات المستقبلية.

---

## الفصل الخامس: التنفيذ والاختبار (Implementation & Testing)

### 5.1 بيئة التنفيذ (Implementation Environment)
تم تنفيذ المشروع باستخدام بيئة تطوير متقدمة تضمن استقرار النظام ومرونته:
- **نظام التشغيل**: Windows 11 Pro / Linux Ubuntu (للاستضافة).
- **بيئة التطوير**: Visual Studio 2022 (لـ .NET) و VS Code (لـ Next.js).
- **محرك قواعد البيانات**: Microsoft SQL Server 2022.
- **إدارة الإصدارات**: Git & GitHub لتعقب التغييرات البرمجية.

### 5.2 مرحلة التنفيذ البرمجي (Codding Phase)
#### 5.2.1 تنفيذ منطق الأعمال (Backend)
تم استخدام لغة **C#** لبناء الخدمات الأساسية، حيث يعتبر مُحرك سير العمل `ApplicationWorkflowService` هو المسؤول عن نقل الطلب بين الحالات المختلفة (Status Transitions) بناءً على نتائج الفروع الأخرى. تم تأمين كافة نقاط الاتصال باستخدام **JWT Token** لضمان عدم وصول أي شخص لبيانات المتقدمين سوى ذوي الصلاحية.

#### 5.2.2 تنفيذ واجهات المستخدم (Frontend)
اعتمدنا على **Next.js 15** لبناء واجهات تفاعلية سريعة. تم استخدام تقنية **Server Components** لتحسين أداء تحميل لوحة التحكم الإحصائية، وتقنية **Client Components** للنماذج التفاعلية (Wizards) التي تتطلب تفاعلاً لحظياً من المستخدم.

### 5.3 مرحلة الاختبار (Testing Phase)
لضمان خلو النظام من العيوب البرمجية، مرّ النظام بثلاث مراحل اختبار أساسية:
1.  **اختبار الوحدات (Unit Testing)**: تم اختبار الدوال الحسابية والمنطقية (مثل دوال التحقق من السن وصلاحية الرخص) بشكل منفصل.
2.  **اختبار التكامل (Integration Testing)**: التأكد من أن البيانات تنتقل بشكل صحيح من المستشفى (نتائج الطبيب) لتظهر فوراً في لوحة تحكم المتقدم.
3.  **اختبار القبول (User Acceptance Testing)**: تمت محاكاة دخول أدوار مختلفة (طبيب، مدقق، متقدم) لتجربة المسار الكامل للطلبات بنجاح.

## الفصل السادس: الخاتمة والتوصيات (Conclusion & Recommendations)

### 6.1 المستخلصات والنتائج (Outcomes)
بعد الانتهاء من تطوير واختبار منصة "مجاز"، تم التوصل للنتائج التالية:
1.  **الرقمنة الكاملة**: بناء نظام قادر على إدارة دورة حياة الرخصة بالكامل دون الحاجة للأوراق.
2.  **الشفافية**: توفير تتبع لحظي للمواطن مما يقلل من الاستفسارات الميدانية.
3.  **الأمان الميداني**: إيجاد وسيلة تحقق سريعة لرجال المرور عبر الـ QR Code تمنع التزوير.

### 6.2 التحديات والحلول (Challenges)
- **التحدي**: صعوبة ربط الجهات الخارجية الحقيقية (المستشفيات، المالية).
- **الحل**: بناء أنظمة محاكاة (Mocks/Simulators) تحاكي البروتوكولات الحكومية الواقعية.

### 6.3 الاستنتاجات والتوصيات (Future Recommendations)
نرى أن مشروع "مجاز" يمثل نواة لنظام مرور وطني شامل، ونوصي بالآتي:
1.  **الذكاء الاصطناعي**: استخدام الـ AI في تحليل صور المتقدمين والتحقق من الهوية الحيوية.
2.  **تطبيقات الجوال**: بناء تطبيقات Native تدعم الـ Offline Mode لحالات التفتيش الميداني الضعيفة الإنترنت.
3.  **التوسع**: إدراج خدمات المركبات (نقل الملكية، اللوحات، التأمين) ضمن المنصة.
