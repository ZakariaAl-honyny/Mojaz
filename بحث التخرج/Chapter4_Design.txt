4.2 المعمارية البرمجية (Software Architecture)
--------------------------------------------------------------------------------

يعتمد المشروع على معمارية Clean Architecture من four طبقات:

الطبقة 1: Domain Layer
- الكيانات (Entities): User, Application, License, Document, etc.
- القيم (Value Objects)
- الواجهات (Interfaces)
- لا تحتوي على أي تبعيات خارجية

الطبقة 2: Application Layer
- الخدمات (Services)
- كائنات النقل (DTOs)
- المدققات (Validators)
- AutoMapper Profiles

الطبقة 3: Infrastructure Layer
- قاعدة البيانات (DB Context)
- المستودعات (Repositories)
- الخدمات الخارجية (External Services)

الطبقة 4: API Layer
- Controllers
- Middleware
- Filters
- Swagger Documentation

4.3 مخططات النظام
--------------------------------------------------------------------------------

أ) مخطط حالات الاستخدام (Use Case Diagram):
المتقدم ─→ تقديم طلب، حجز موعد، سداد، استلام
الاستقبال ─→ تدقيق الوثائق، قبول، رفض
الطبيب ─→ فحص طبي، تحديد لياقة
الفاحص ─→ اختبار نظري، اختبار عملي
المدرب ─→ تدريب، تقييم مهارات
المدير ─→ اعتماد، إصدار
الأمن ─→ تحقق via QR

ب) مخطط النشاط (Activity Diagram):
[البداية] ─→ تقديم الطلب ─→ تدقيق ─→ فحص طبي ─→ 
سداد ─→ تدريب ─→ اختبارات ─→ اعتماد ─→ إصدار ─→ [النهاية]

ج) مخطط التتابع (Sequence Diagram):
المتقدم → API → Database
API → External Services (SMS/Email)
Database ← API
