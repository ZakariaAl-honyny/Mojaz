# مكتبة المكونات — منصة مُجاز

## مقدمة

توثّق هذه المكتبة جميع المكونات البرمجية المستخدمة في تطوير الواجهة الأمامية لمنصة إلكترونية متكاملة لإدارة رخص القيادة، وهي مبنية بأحدث التقنيات الويب الحديثة، وتحديداً إطار عمل نكست ج إس 15 مع مكتبة ريأكت، ومكتبة شاد سي إن يو للمكونات الأساسية، مع مراعاة كاملة لدعم اللغة العربية والاتجاه من اليمين إلى اليسار.

تتبّع المكتبة منهجية التصميم المعتمد في المبادئ الحكومية للمنصات الرقمية اليمنية، حيث يتم استخدام اللون الأزرق الملكي كم색 أساسي وهوية بصرية موحدة عبر جميع المكونات، مما يضمن تجربة استخدام متسقة ومتماسكة للمستخدمين.

## القسم الأول: مكونات واجهة المستخدم الأساسية

### 1.1 المكون Button — الزري

#### الوصف

مكون الزري هو أحد أهم عناصر التفاعل في المنصة، ويُستخدم لتمكين المستخدم من تنفيذ إجراءات متنوعة داخل النماذج والصفحات. يدعم هذا المكون عدة أنماط_visuals وأنماط وأحجام مختلفة لتناسب جميع سياقات الاستخدام، من الأزرار الأساسية年到 الأزرار الثانوية，再到 أزرار الإجراءات الخطيرة كالحذف والإلغاء.

يعتمد المكون على مكتبة كلاس فاريانس أوثوريتي لإدارة الأنماط بشكل declarativo، مما يسهّل توسيعه وتخصيصه وفقاً للاحتياجات الخاصة بالمنصة. يدعم المكون أيضاً حالات مختلفة تشمل التفعيل والتعطيل والتحميل، مع انتقالات سلسة بين هذه الحالات لتحسين التجربة البصرية للمستخدم.

#### الخصائص والمعاملات

المكون يقبل المعاملات التالية:

- خاصية variant: تُحدد النمط_البصري للزري، وقيمها المتاحة هي: default ويُستخدم للزرار الأساسية باللون الأزرق الملكي inherit، destructive للزرار التي تُنفذ إجراءات خطرة كالحدف، outline للزرار ذات الحدود فقط، secondary للزرار الثانوية، ghost للزرار الشفافة، وlink للروابط التي تظهر كزرار.

- خاصية size: تُحدد حجم الزري، والقيم المتاحة هي: default للحجم الافتراضي، small للحجم الصغير، large للحجم الكبير، icon للأيقونات المربعة، icon_small للأيقونات الصغيرة جداً، وicon_large للأيقونات الكبيرة.

- خاصية asChild: قيمة منطقية تُحدد ما إذا كان المكون سيستخدم كمكون Slot لتقليد عنصر آخر.

- خاصية className: للنمط المخصص الإضافي.

#### مثال الاستخدام

```tsx
import { Button } from '@/components/ui/button';

<Button variant="default" size="default">
  تقديم الطلب
</Button>

<Button variant="outline" size="sm">
  إلغاء
</Button>

<Button variant="destructive" size="lg">
  حذف المستند
</Button>
```

### 1.2 المكون Input — حقل الإدخال

#### الوصف

يُستخدم مكون حقل الإدخال لجمع البيانات النصية من المستخدمين بشكل يسير ومريح. يدعم هذا المكون جميع أنواع المدخلات النصية المعتادة كنص وكلمة مرور وبريد إلكتروني ورقم هاتف، مع تطبيق أنماط_visuals متسقة مع هوية المنصة البصرية.

يتضمن المكون أنماطاً خاصة للتركيز والخطأ والتحقق، مع استخدام خصائص CSS المنطقية لضمان عمل صحيح في الاتجاه من اليمين إلى اليسار. يدعم المكون أيضاً ملفات الأنماط المخصصة ويمكن توسيعه ليشمل حالات التحقق من الصحة والأخطاء.

#### الخصائص والمعاملات

المكون يقبل جميع الخصائص الأصلية لعنصر الإدخال في HTML، بالإضافة إلى:

- خاصية type: تُحدد نوع المدخلات النصيةكنص أو número أو بريد إلكتروني أو كلمة مرور.

- خاصية placeholder: النص الإرشادي الذي يظهر داخل الحقل عندما يكون فارغاً.

- خاصية className: للأنماط الإضافية المخصصة.

#### مثال الاستخدام

```tsx
import { Input } from '@/components/ui/input';

<Input 
  type="text" 
  placeholder="أدخل رقم الهوية الوطنية" 
  name="nationalId"
/>

<Input 
  type="email" 
  placeholder="البريد الإلكتروني" 
  name="email"
/>
```

### 1.3 المكون Select — القائمة المنسدلة

#### الوصف

يُوفر مكون القائمة المنسدلة طريقة سهلة وبديهية لاختيار قيمة واحدة من مجموعة خيارات محددة مسبقاً. يعتمد هذا المكون على مكتبة رادياس يو إيه لتوفير تجربة مستخدم غنية وتفاعلية، مع دعم كامل للتنقل بلوحة المفاتيح وإمكانية البحث ضمن الخيارات.

يتضمن المكون عدة أجزاء فرعية تشمل trigger الذي يُعرض القيمة المختارة، وcontent الذي يُحتوئ قائمة الخيارات، وitem الذي يُمثل كل خيار متاح. يدعم المكون أيضاً التحجيم حسب احتياجات الاستخدام، مع أنماط مرئية متسقة مع باقي مكونات المكتبة.

#### الخصائص والمocalypticات

- خاصية value: القيمة المختارة حالياً.

- خاصية onValueChange: دالة تستدعى عند تغيير القيمة.

- خاصية placeholder: النص المُعرض عندما لا توجد قيمة مختارة.

- خاصية disabled: لتعطيل المكون.

- خاصية size: حجم المكون可以是 default أو small.

- خاصة children: مجموعة من المكونات SelectItem.

#### مثال الاستخدام

```tsx
import { Select, SelectTrigger, SelectValue, SelectContent, SelectItem } from '@/components/ui/select';

<Select onValueChange={(value) => console.log(value)}>
  <SelectTrigger>
    <SelectValue placeholder="اختر المدينة" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="sanaa">صنعاء</SelectItem>
    <SelectItem value="taiz">تعز</SelectItem>
    <SelectItem value="ibb">إب</SelectItem>
  </SelectContent>
</Select>
```

### 1.4 المكون Checkbox — خانة الاختيار

#### الوصف

يُستخدم مكون خانة الاختيار للسماح للمستخدم بتحديد خيار واحد أو أكثر من مجموعة خيارات متعلقة بعضهابعضها. يعتمد هذا المكون على مكتبة بيس يو آي ويتميز بحجمه المناسب وأسلوبه البصري النظيف الذي يتناسق مع هوية المنصة التصميمية.

يتضمن المكون علامة صح تفاعلية تُظهر عند التفعيل، مع دعم كامل لحالات الخطأ والتحقق. يدعم المكون أيضاً حالات التفعيل المتعددة والخاصة بالتحقق من صحة النماذج.

#### الخصائص والمعاملات

- خاصية checked: حالة التفعيل الحالية.

- خاصية onCheckedChange: دالة تستدعى عند تغيير حالة التفعيل.

- خاصية disabled: لتعطيل المكون.

- خاصية required: لجعل الاختيار مطلوباً.

- خاصية className: للأنماط الإضافية.

#### مثال الاستخدام

```tsx
import { Checkbox } from '@/components/ui/checkbox';

<Checkbox 
  checked={agreed} 
  onCheckedChange={(checked) => setAgreed(checked)}
/>

<span>أوافق على الشروط والأحكام</span>
```

### 1.5 المكون RadioGroup — مجموعة أزرار الاختيار

#### الوصف

يُستخدم مكون مجموعة أزرار الاختيار عندما يكون الاختيار من خيار واحد فقط من بين عدة خيارات متنافية. يوفر هذا المكون واجهة بصرية نظيفة ومألوفة للمستخدمين، مع دعم كامل للتنقل بلوحة المفاتيح.

يعتمد المكون على مكتبة رادياس يو إيه، ويتضمن جزأين رئيسيين: RadioGroup الذي يُحتوئ المجموعة بأكملها، وRadioGroupItem الذي يُمثل كل خيار فردي. يُعرض الخيار المحدد بنقطة زرقاء في المنتصف.

#### الخصائص والمumatices

- خاصية value: القيمة المختارة حالياً.

- خاصية onValueChange: دالة تستدعى عند تغيير القيمة.

- خاصية disabled: لتعطيل المجموعة بالكامل.

- خاصةchildren: مجموعة من RadioGroupItem.

#### مثال الاستخدام

```tsx
import { RadioGroup, RadioGroupItem } from '@/components/ui/radio-group';

<RadioGroup onValueChange={setGender}>
  <RadioGroupItem value="male">ذكر</RadioGroupItem>
  <RadioGroupItem value="female">أنثى</RadioGroupItem>
</RadioGroup>
```

### 1.6 المكون Card — البطاقة

#### الوصف

يُستخدم مكون البطاقة لتجميع المحتوى ذي الصلة في وحدة واحدة متماسكة، وهو مثالي لعرض معلومات الطلبات والرخص والخدمات بشكل منظم وجذاب بصرياً. يتكون من عدة أجزاء فرعية تشمل الترويسة والمحتوى والتذييل.

يعتمد هذا المكون على تصميم مرن يدعم المحتوى المتغير الطول والأقسام المتعددة، مع أنماط ظل ورموز الحدود المتسقة مع هوية المنصة البصرية. يدعم المكون أيضاً التوسع الأفقي والرأسي حسب المحتوى الداخلي.

#### الأجزاء الفرعية

- Card: الحاوية الرئيسية.

- CardHeader: ترويسة البطاقة.

- CardTitle: عنوان البطاقة.

- CardDescription: وصف البطاقة.

- CardAction: إجراء مرتبط بالبطاقة.

- CardContent: المحتوى الرئيسي.

- CardFooter: تذييل البطاقة.

#### مثال الاستخدام

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@/components/ui/card';

<Card>
  <CardHeader>
    <CardTitle>معلومات الطلب</CardTitle>
    <CardDescription>تفاصيل طلب رخصة القيادة</CardDescription>
  </CardHeader>
  <CardContent>
    <p>رقم الطلب: MOJ-2025-48291037</p>
    <p>الحالة: قيد المراجعة</p>
  </CardContent>
  <CardFooter>
    <Button>عرض التفاصيل</Button>
  </CardFooter>
</Card>
```

### 1.7 المكون Dialog — النافذة المنبثقة

#### الوصف

يُستخدم مكون النافذة المنبثقة لعرض محتوى تفاعلي في طبقة علوية فوق الصفحة الحالية، وهو مثالي لعرض نماذج الإدخال والإشعارات والتحذيرات دون مغادرة الصفحة الحالية. يعتمد على مكتبة بيس يو آي ويتميز بظهور وانتقال سلسين.

يتضمن المكون عدة أجزاء فرعية تشمل الأساس للتحكم في حالة الفتح والإغلاق، والطبقة الخلفية المعتمة، والمحتوى الفعلي للنافذة، ومختلف عناصر التحكم كالعنوان والوصف وزر الإغلاق.

#### الأجزاء الفرعية الأساسية

- Dialog: الحاوية الرئيسية.

- DialogTrigger: زر أو رابط يفتح النافذة.

- DialogContent: محتوى النافذة.

- DialogHeader: ترويسة النافذة.

- DialogTitle: عنوان النافذة.

- DialogDescription: وصف النافذة.

- DialogFooter: تذييل النافذة.

- DialogClose: زر الإغلاق.

#### مثال الاستخدام

```tsx
import { Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter } from '@/components/ui/dialog';

<Dialog>
  <DialogTrigger>
    <Button>تعديل البيانات</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>تعديل الملف الشخصي</DialogTitle>
      <DialogDescription>قم بتعديل بياناتك الشخصية هنا</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <Button variant="outline">إلغاء</Button>
      <Button>حفظ التغييرات</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

يدعم المكون الانزلاق من أربعة اتجاهات: من الأعلى والأسفل ومن اليمين ومن اليسار، مع دعم كامل للاتجاه المعكوس في وضع اللغة الإنجليزية. يتضمن انتقالات سلسة ومنظمة.

#### الخاصية side

- top: من الأعلى.

- bottom: من الأسفل.

      <Link href="/dashboard">لوحة التحكم</Link>

يتضمن الأجزاء الأساسية لجدول HTML مع أنماط متسقة مع هوية المنصة البصرية، بما في ذلك الترويسة والجسم والتذييل والتسميات التوضيحية.

### 1.10 المكون Pagination — ترقيم الصفحات

#### الوصف

يُستخدم مكون ترقيم الصفحات للتنقل بين صفحات البيانات المقسمة، وهو ضروري لعرض القوائم الطويلة بطريقة منظمة تتجنب تحميل جميع السجلات دفعة واحدة. يعتمد على تصميم مرن يدعم مختلف أحجام البيانات.

يتضمن مكونات للتنقل往前 و往後، والترقيم المباشر، وعلامات الإلغاء للحالات التي لا يمكن التنقل فيها.

#### مكونات الترقيم

- Pagination: الحاوية الرئيسية.

- PaginationContent: المحتوى الداخلي.

- PaginationItem: عنصر ترقيم واحد.

- PaginationLink: رابط التنقل.

- PaginationPrevious: زر الصفحة السابقة.

- PaginationNext: زر الصفحة التالية.

- PaginationEllipsis: علامة تعدد الصفحات.

#### مثال الاستخدام

```tsx
import { Pagination, PaginationContent, PaginationItem, PaginationLink, PaginationNext, PaginationPrevious } from '@/components/ui/pagination';

<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="?page=1" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="?page=1">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="?page=2">2</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="?page=2" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

### 1.11 المكون Form — النموذج

#### الوصف

يُستخدم مكون النموذج لجمع وتحقق من صحة بيانات المستخدم باستخدام مكتبة رياكت هوك فورم. يتكامل بسلاسة مع مكونات الإدخال في المكتبة ويوفر نظاماً شاملاً للتحقق والأخطاء.

يعتمد على مفهوم الحقول controlled التي تدير حالة كل حقل فردي، ويوفر حقول سياق مشتركة للوصول إلى حالة النموذج ومعلومات التحقق في أي مكون فرعي.

#### مكونات النموذج

- Form: حاوية السياق.

- FormField: حقل نموذج واحد.

- FormItem: عنصر النموذج الفردي.

- FormLabel: تسمية الحقل.

- FormControl: تحكم الحقل.

- FormDescription: وصف الحقل.

- FormMessage: رسالة الخطأ أو التحقق.

#### مثال الاستخدام

```tsx
import { Form, FormField, FormItem, FormLabel, FormControl, FormDescription, FormMessage } from '@/components/ui/form';

<Form>
  <FormField
    name="nationalId"
    render={({ field }) => (
      <FormItem>
        <FormLabel>رقم الهوية</FormLabel>
        <FormControl>
          <Input placeholder="أدخل رقم الهوية" {...field} />
        </FormControl>
        <FormDescription>رقم الهوية الوطنية或个人ية</FormDescription>
        <FormMessage />
      </FormItem>
    )}
  />
</Form>
```

### 1.12 المكون Calendar — التقويم

#### الوصف

يُستخدم مكون التقويم لاختيار التواريخ بشكل بصري وتفاعلي، وهو مثالي لاختيار مواعيد الحضور وتواريخ الميلاد及其它 التواريخ المهمة. يعتمد على مكتبة رياكت دايبيكر ويتميز بدعم كامل للتقويم الهجري.

يتضمن المكون دعم كامل للتنقل بين الأشهر والسنوات، وتحديد النطاق المسموح به، والتظليل المرئي للتواريخ المختارة والمحددة وغيرها. يدعم المكون أيضاً التخصيص الكامل للأيقونات والانتقالات.

#### مثال الاستخدام

```tsx
import { Calendar } from '@/components/ui/calendar';

<Calendar 
  mode="single"
  selected={selectedDate}
  onSelect={(date) => setSelectedDate(date)}
  disabled={(date) => date < new Date()}
/>
```

### 1.13 المكون Toast — الإشعار المؤقت
