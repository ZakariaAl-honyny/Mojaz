================================================================================
                    مخطط علاقات الكيانات (ERD)
                  لمنصة مُجاز - رخصة القيادة الحكومية
================================================================================

================================================================================
                            المقدمة
================================================================================

يوضح هذا المستند مخطط علاقات الكيانات لقاعدة بيانات منصة مُجاز، وهي منصة حكومية
متخصصة في إدارة إجراءات إصدار رخص القيادة. يعتمد التصميم على نمط Clean Architecture
ويستخدم Entity Framework Core مع SQL Server.

يتضمن المخطط 21 جدولاً تمثل الكيانات الأساسية والفرعية للمنصة.

================================================================================
                    1. الكيانات الرئيسية (Main Entities)
================================================================================

================================================================================
                    5. قواعد التصميم
================================================================================

5.1 الحذف الناعم (Soft Delete)
-------------------------------
- جميع الكيانات باستثناء AuditLog و Notification تستخدم الحذف الناعم
- عمود IsDeleted (bit) مع Default = 0
- عمود DeletedAt (datetime2) لتتبع وقت الحذف
- عمود DeletedBy (uniqueidentifier) لتتبع من قام بالحذف

5.2 التدقيق (Auditing)
------------------------
- BaseEntity: Id, CreatedAt, UpdatedAt
- AuditableEntity: يضيف CreatedBy, UpdatedBy
- SoftDeletableEntity: يضيف IsDeleted, DeletedAt, DeletedBy
- AuditLog: سجل منفصل للتدقيق

5.3 المفاتيح الخارجية
------------------------
- RESTRICT only (لا حذف متسلسل)
- جميع العلاقات الاختيارية تستخدم ON DELETE SET NULL
- جميع العلاقات الإلزامية تستخدم ON DELETE NO ACTION

5.4 الترقيم
------------
- IDs: uniqueidentifier (GUID)
- ApplicationNumber: MOJ-{YEAR}-{8_RANDOM_DIGITS}
- LicenseNumber: MOJ-{YEAR}-{8_RANDOM_DIGITS}

5.5 التواريخ
-------------
- جميع التواريخ محفوظة بالتوقيت العالمي (UTC)
- datetime2 بدقة عالية
