# الفصل الخامس: التنفيذ والاختبار (Implementation & Testing)

## 5.1 مقدمة (Introduction)
يستعرض هذا الفصل الأدوات والتقنيات الفعلية التي استخدمت في بناء الكود البرمجي لمنصة "مجاز"، مع شرح لآليات الاختبار المتبعة لضمان أمان البيانات وسلامة منطق الأعمال في دورة حياة رخصة القيادة.

## 5.2 التقنيات البرمجية المستخدمة

### 5.2.1 جانب الخادم (Backend Environment)
-   **#C / .NET 8**: اللغة الأساسية لبناء الـ Web APIs.
-   **Entity Framework Core**: لإدارة الكيانات البرمجية (ORM) وتسهيل التعامل مع الـ Migrations.
-   **AutoMapper**: لربط النماذج الداخلية (Entities) بنماذج العرض (DTOs).
-   **FluentValidation**: لضمان أن البيانات المدخلة تتبع القواعد الحكومية قبل حفظها.

### 5.2.2 جانب العميل (Frontend Environment)
-   **React / Next.js 15**: الإطار الأحدث لبناء تطبيقات الويب الدينـاميكية مع دعم التوجيه (App Router).
-   **TypeScript 5**: لضمان جودة الكود وتفادي أخطاء النوع (Type Safety).
-   **shadcn/ui**: لتوفير مكونات واجهة مستخدم (Buttons, Modals, Tables) عالية الأداء ومتوافقة مع المعايير الحكومية.
-   **React Query**: لإدارة عمليات جلب البيانات وتحديثها لحظياً دون الحاجة لإعادة تحميل الصفحة.

## 5.3 تنفيذ خدمات التكامل (Integration Implementation)
-   **نظام الإشعارات اللحظي**: تم استخدام **Firebase Cloud Messaging (FCM)** لإرسال تنبيهات (Push Notifications) للمتقدم بـمجرد تغيير حالة طلبه من "قيد المراجعة" إلى "موافق عليه".
-   **التوثيق برمز التحقق (OTP)**: تكامل النظام مع API خارجي (محاكاة أو عبر Twilio) لإرسال رسائل SMS برمز سري يُستخدم عند التسجيل وتغيير كلمة المرور.

## 5.4 اختبارات النظام (System Testing)

### 5.4.1 اختبار الوحدات (Unit Testing)
تم كتابة اختبارات آلية لكل خدمة (Service) للتأكد من حساباتها المنطقية. مثلاً: تم اختبار دالة `CalculateAge` للتأكد أنها لا تسمح لمواطن عمره 17 عاماً بالتقديم على رخصة الفئة C (التي تتطلب سن 21).

### 5.4.2 اختبار الصندوق الأسود (Black Box Testing)
تم تجربة المسار الكامل للمستخدم (The Happy Path):
1.  التسجيل والتحقق.
2.  تقديم طلب جديد بنجاح.
3.  سداد رسوم المحاكاة.
4.  رصد نتيجة الطبيب "لائق" بنجاح.
5.  رصد نتيجة الاختبار "ناجح" وتوليد الرخصة الرقمية.

### 5.4.3 اختبار الثبات (Stress Testing)
تم محاكاة دخول 100 مستخدم في آن واحد للتأكد من قدرة الـ Server على معالجة الطلبات دون تأخير ملحوظ.

## 5.5 نتائج التنفيذ (Implementation Results)
أسفرت عملية التنفيذ عن منصة متكاملة وفعالة:
-   **واجهة المتقدم**: تظهر الطلبات بوضوح مع إمكانية التتبع.
-   **لوحة تحكم المدير**: توفر إحصائيات بصرية (Charts) عبر مكتبة **Recharts**.
-   **توليد التقارير المعتمد**: القدرة على استخراج الرخصة بصيغة PDF تحتوي على **QR Code** للتحقق الميداني من صحة الرخصة.
*(ملاحظة: سيتم إدراج لقطات شاشة من النظام الفعلي في النسخة المطبوعة).*
