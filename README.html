النظرة العامة

مُجاز (*Mojaz*) — تعني بالعربية "المرخّص" أو "المصرّح له"

منصة حكومية رقمية شاملة لإدارة دورة حياة رخصة القيادة بالكامل — من التقديم للإصدار — بشكل كامل عبر الإنترنت. مستوحاة من تصميم نظام أبشر، توفر تجربة حكومية رسمية حديثة مع دعم كامل للعربية (RTL) والإنجليزية (LTR).

التثبيت

# استنساخ المشروع
git clone https://github.com/ZakariaAl-honyny/Mojaz.git
cd mojaz

# تشغيل قاعدة البيانات
docker-compose up -d sqlserver

# تشغيل الخفي
cd src/backend/Mojaz.API
dotnet run

# تشغيل الواجهة
cd src/frontend
npm run dev
